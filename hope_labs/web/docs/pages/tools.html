The Tools page

Every tool the lab runs on Grace, a block each, saying what it does, whether it is running, and what it hands on.

A block

  • The name, and beside it the tool's category, or running while it is up.
  • One line saying what you would use it for, and under it what it does.
  • takes and leaves: what another tool can hand it, and what it leaves for the next one. HOPE-MD is the one that takes something from the others.
  • Launch, or Open once the tool is running, and Stop beside it then.
  • The dashed buttons, such as → HOPE-MD: the tool that usually comes next in the lab's order of work. Hold the pointer over one to see the step it stands for.

Launching a tool

Launch opens the tool's window straight away. The window starts the tool on the login node and shows that it is doing so; the page it then shows is the tool's own. The block says running once the tool is up, and the dot beside its name on the left turns green. The page reads the tools' state a few seconds after you press Launch, and every fifteen seconds after that.

The window opens inside your click. Chrome lets a page open a window only while the click that asked for it is fresh, about five seconds, and starting a tool takes longer than that. So the window comes first, and the window starts the tool. If nothing opens at all, Chrome blocked it: see Allow its windows.

A tool has one window. Open, its name on the left, and a dashed button anywhere else that leads to it all bring that window forward rather than starting a second copy of the tool. See One window per tool.

Stopping a tool

Stop ends the tool's page server on the login node and closes the port forwarded to it. It does not touch anything the tool submitted: queued and running jobs carry on, and their run folders stay where they are. Launch the tool again to see them.

Finding a tool

With five tools the page fits on one screen, and the categories and the search are there for when it does not. The count beside the heading says how many blocks are shown, of how many, and how many tools are running.

The column on the left

The dark column on the left is the same in both views. Under The tools it lists every tool, with a dot that is green while the tool is running; clicking a name opens its window, as Launch or Open would. The note at its foot is the one thing to remember about cost: every tool runs under your own account, and the jobs it submits are charged to you.
