How to cite

HOPE Labs opens the tools; it does none of the science. Cite the tools whose results you report, and acknowledge the computing.

The tools

Each tool records in its runs what it used, and each tool's own documentation says how to cite it. Cite from there.

The methods the tools run, AlphaFold, ProteinMPNN, ADCP, Amber, OpenMM, GROMACS, NAMD, Desmond and the rest, belong to their authors.

The computing

Everything here runs on Texas A&M's clusters. HOPE Labs prints this sentence in its log each time you sign in, for the acknowledgements of anything that used them:

Please acknowledge Texas A&M High Performance Research Computing (HPRC) for the computational resources.

HOPE Labs itself

HOPE Labs is by Aadhil Haq, HOPE Lab (PI Dr. Sandun Fernando), Texas A&M University. It is a launcher, and a paper's methods rarely need it; if yours does, name it with its version, which the bar along the bottom of its page shows.
