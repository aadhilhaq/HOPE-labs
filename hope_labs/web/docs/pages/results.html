Results

The run folders of all seven tools in one list, newest first, each beside the step that usually follows it.

What is listed

Results looks in the folders each tool writes its runs to, on Grace, over the connection already open, and lists the twelve newest runs in each folder, newest first. A run is listed by its folder's name, with the full path under it, the tool that made it, and how long ago the folder was last modified.

ToolWhere its runs are looked for

HOPE-Aptamer$SCRATCH/hope-aptamer-runs
BindCraft2/scratch/group/sflab/bindcraft_runs/ and your NetID

HOPE-MD/scratch/group/sflab/hopemd_runs and $SCRATCH/hopemd_runs

These are where each tool writes when it is not told otherwise, which is how HOPE Labs starts them. A run written somewhere else is not listed; open it from its own tool.

Refresh looks again. Otherwise what was read is kept for twenty seconds, so moving between the views does not ask Grace each time.

The buttons along the top show one tool's runs, with the number of its runs beside its name. Pick it again, or All tools, to see every run.

Results lists folders; it does not read them. A folder is listed whether the run in it finished, failed or is still going. Open the run in its own tool to see which.

Handing a run on

The last column holds the step that usually follows a run of that kind: Simulate these poses in HOPE-MD beside a docking run, Dock a design in ADCP and Simulate a design in HOPE-MD beside a peptide-design run. Pressing one opens the tool that takes the run, in its own tab, which shows the run's folder with a Copy path button and copies it for you on the way to the tool: see Handing on a run. Paste the path into that tool's import box.

A HOPE-MD run says none there: nothing in the lab's order of work comes after a simulation.
