A tool's tab

Each tool opens in a tab of its own, on the tool's own page: the same page its own launcher opens, with nothing of HOPE Labs around it.

The page in the tab is the tool's, down to its own Docs button and the bar along its bottom. Its buttons, its file browser and its fetches work as they do when the tool is opened on its own, because that is what it is. To reach another tool, go back to the HOPE Labs tab and pick it there.

While it starts

A tool that is not running yet is started by its tab, which shows Starting and the tool's name while it waits. The first start of the day can take up to a minute while the tool's environment loads on the login node. HOPE Labs waits up to two minutes for the tool to say it is ready. Past that, or if the tool stops before then, the tab says why, with a Try again button; When something goes wrong lists those messages.

One tab per tool

Each tab is named after its tool, so asking for a tool again, from its block or from the column on the left, goes back to its tab instead of starting a second copy of the tool. A tab already showing the tool is only brought forward, not loaded again, so a form you had filled in there is kept. Whether your browser also switches to that tab by itself depends on the browser; if it does not, the tab is the one with the tool's name.

Closing a tab does not stop its tool. It keeps running on the login node until you press Stop on its block or sign out, and opening it again is quick.

Handing on a run

When a tab is opened from a run in Results, it shows the run's folder with a Copy path button while the tool starts, and waits for one more click when the tool is ready: Copy the path and open the tool. The tools' own pages cannot yet be opened on a folder, so the path is handed over by hand: it goes on the clipboard, and you paste it into the tool's import box. If your browser will not let the page copy, the path is selected for you instead, ready for Ctrl+C, and the button becomes Open the tool.
