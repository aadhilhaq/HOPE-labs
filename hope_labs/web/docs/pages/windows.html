A tool's window

Each tool opens in a window of its own: the tool's own page, under a thin bar that reaches every other tool.

The bar

PartWhat it does
The name and its lineWhich tool this window is.
open nextA button for every other tool. The dashed ones, marked with an arrow, are the tools that usually come after this one in the lab's order of work; hold the pointer over one to see the step. Each opens that tool's own window, starting the tool if it is not up.
Plain pageOpens the tool's page in a tab without this bar, for anyone who would rather have the tool alone. It is the same page, through the same connection.
All toolsOpens the Tools page.
StopStops this tool, as Stop on its block does. The window can then be closed.
HOPE Labs docsOpens these pages. The tool's own documentation is behind the Docs button on its page, under the bar.

While it starts

A tool that is not running yet is started by its window, which shows Starting and the tool's name under the bar while it waits. The first start of the day can take up to a minute while the tool's environment loads on the login node. HOPE Labs waits up to two minutes for the tool to say it is ready. Past that, or if the tool stops before then, the window says why in a message at the bottom right; When something goes wrong lists those messages.

One window per tool

Each window is named after its tool, so asking for a tool again, from its block, from the column on the left or from another tool's bar, brings its window forward instead of starting a second copy of the tool. The window's page is loaded again when that happens, so a form you had filled in there and not yet submitted may need filling in again.

Closing a window does not stop its tool. It keeps running on the login node until you press Stop or sign out, and opening it again is quick.

Handing on a run

When a window is opened from a run in Results, the run's folder is shown under the bar with a Copy path button. The tools' own pages cannot yet be opened on a folder, so the path is handed over by hand: copy it, and paste it into the tool's import box. If your browser will not let the page copy, the path is selected for you instead, ready for Ctrl+C.
